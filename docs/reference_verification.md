## 查證方式說明

每筆文獻皆透過以下方式交叉確認，而非僅依賴單一來源：
1. 出版社官方頁面（journals.sagepub.com、dl.acm.org、pubsonline.informs.org、tandfonline.com、sciencedirect.com、mdpi.com、jmir.org 等）
2. 至少一個獨立索引資料庫核對（Semantic Scholar、PubMed、JSTOR、DOAJ 之一以上）
3. 確認作者、發表年、期刊卷期頁碼三者與本論文引用內容完全一致

## 使用建議

- 點擊任一DOI連結（https://doi.org/... 開頭）即可導向出版社官方頁面，這是學術引用中最標準、最不會失效的查證方式
- 3篇標記「完全開放取用」的文獻（#8、#14、#15、#16共4篇，其中Marocco/Tun/Vereschak三篇）可直接下載完整PDF，適合優先精讀
- 其餘期刊付費文獻，可透過成大圖書館資料庫（如有訂閱該期刊）或洽指導教授索取全文
- 若正式論文需要在文獻清單附上「已下載全文」的證明，建議將各篇PDF另存於 `docs/references_pdf/`（此資料夾目前為空，需自行下載後歸檔，因版權關係本工具不代為下載期刊全文）
