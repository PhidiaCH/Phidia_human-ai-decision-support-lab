# 研究架構與操作型定義（正式文件版 v1）
情境化AI決策支援對智慧製造管理者資訊理解、信任與決策採用意願之影響

---

## 1. 研究架構圖（文字版）

```
AI決策資訊品質(情境化) --H1--> 資訊理解 --H2--> AI信任 --H3--> 決策採用意願/行動意願
                                    |                  |                ^
                                    |--------H4（直接效果，穩健性檢定）---|
                                    |                  |
                                    +--------H5---------+
                                              |
                                              v
                                       感知決策品質（中介）

控制變數：AI使用經驗、職級／年資、任務複雜度
```

## 2. 構念之操作型定義

### 2.1 AI決策資訊品質（情境化）Contextualized AI Decision Information Quality
**定義**：AI決策建議所附帶的情境化資訊完整度，包含證據來源可追溯性、風險分級明確度、建議信心水準揭露程度。此構念以實驗操弄（A組=一般資訊／B組=情境化AI建議）呈現，非以量表題項測量，屬本研究的自變項操弄檢核（manipulation）。
**理論來源**：DeLone & McLean IS成功模式（資訊品質構面）

**操弄檢核建議**：可於B組受測後加問「本次AI建議是否附有風險等級／證據來源／信心水準？」（是／否）作為操弄成功與否的檢核題。

### 2.2 資訊理解 Information Understanding
**定義**：管理者對案件問題本質、影響範圍、關鍵資訊來源的清楚程度。
**理論來源**：IS成功模式
**題項（3題，Likert 5點，1=非常不同意，5=非常同意）**：
1. 我清楚知道這個案件目前面臨的問題是什麼
2. 我理解這個決策可能帶來的影響
3. 我對案件的關鍵資訊來源感到清楚

### 2.3 AI信任 Trust in AI
**定義**：管理者對AI決策建議判斷準確性、證據可靠性、專業能力與整體安心程度的信任評估。
**理論來源**：Mayer, Davis & Schoorman (1995)；Lee & See (2004)
**僅於B組蒐集**（A組無AI建議可評估）
**題項（4題，Likert 5點）**：
1. 我認為這個AI建議的判斷是準確的
2. 我認為AI提供的證據來源可靠
3. 我認為這個AI建議具備足夠的專業能力
4. 我對採用這個AI建議感到安心

### 2.4 感知決策品質 Perceived Decision Quality
**定義**：管理者對最終決策的品質、風險控制效果、資源運用效度的整體評估，作為資訊理解／AI信任與決策採用意願間的中介變項。
**理論來源**：Task-Technology Fit (Goodhue & Thompson, 1995)
**題項（3題，Likert 5點）**：
1. 我認為這個決策的品質很高
2. 我認為這個決策能有效控制風險
3. 我認為投入的資源運用得當

### 2.5 決策採用意願／行動意願 Decision Adoption Intention
**定義**：管理者未來願意採用類似AI決策輔助介面、並將其推薦給同事使用的行為意圖。
**理論來源**：TAM (Davis, 1989)
**題項（3題，Likert 5點）**：
1. 我願意採用這個決策建議
2. 未來遇到類似案件，我願意持續使用這樣的AI輔助
3. 我願意向同事推薦使用這樣的系統

### 2.6 決策信心（單題，行為量測，非構念量表）
**定義**：管理者對自己所做決策結果的主觀信心程度，用於補充行為資料的解釋力，不納入構念信度計算。
**題項（1題，Likert 5點，1=非常低，5=非常高）**：
「我對這個決策結果的信心程度」

### 2.7 行為資料（Behavioral Data，非自陳量表）
| 變項 | 定義 | 蒐集方式 |
|---|---|---|
| 最終決策 | 是否將案件升級為公司重大風險處理 | 二元選擇（升級／不升級） |
| 閱讀情境耗時 | 從情境頁面顯示到點擊「進入決策」的秒數 | 系統自動記錄時間戳 |
| 決策耗時 | 從進入決策頁面到提交的秒數 | 系統自動記錄時間戳 |

### 2.8 控制／調節變數
| 變項 | 量測方式 |
|---|---|
| AI使用經驗 | 單題 Likert 5點：「您平時使用AI工具輔助工作決策的頻繁程度」 |
| 職級 | 類別變項：協理／處長以上、經理／副理、其他 |
| 產業別 | 類別變項：半導體／電子製造、傳統製造、金融保險、零售服務、科技軟體、其他 |
| 情境類型 | 依篩選題（是否涉及製造／品保／供應鏈決策）分派：製造情境／通用情境 |

## 3. 研究假設對照表

| 假設 | 內容 | 檢定方法 |
|---|---|---|
| H1 | 情境化AI決策資訊品質正向影響資訊理解 | 獨立樣本t-test（A組 vs B組之資訊理解平均） |
| H2 | 資訊理解正向影響AI信任 | 迴歸分析（僅B組） |
| H3 | AI信任正向影響決策採用意願 | 迴歸分析（僅B組） |
| H4 | 資訊理解正向影響決策採用意願（直接效果） | 階層迴歸（控制AI信任後之直接效果，穩健性檢定） |
| H5 | 資訊理解、AI信任透過感知決策品質間接影響決策採用意願 | 中介分析（Bootstrap法／PROCESS巨集邏輯，或正式SEM間接效果檢定） |

## 4. 信效度標準

- **內部一致性信度**：Cronbach's α ≥ .70 為可接受，≥ .80 為良好
- **內容效度**：正式施測前由3-5位具製造業管理或AI導入實務經驗之專家，就每一題項進行「相關性」「清晰度」評分（見 `content_validity_review.md`）
- **建構效度**：正式資料蒐集完成後，以驗證性因素分析（CFA）檢驗四構念的收斂效度（AVE ≥ .50）與區別效度（Fornell-Larcker準則）
