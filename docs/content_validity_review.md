# 專家內容效度審查表（正式施測前使用）
情境化AI決策支援對智慧製造管理者資訊理解、信任與決策採用意願之影響

**使用時機**：正式發放問卷前，邀請3-5位具製造業管理或AI導入實務經驗之專家（如VPO主管、EMBA同學中具相關背景者、指導教授推薦人選），對每一題項評分。
**目的**：計算內容效度指標（Content Validity Index, CVI），並蒐集題項修改建議。

---

## 填寫說明

請針對下列每一題項，就「相關性」與「清晰度」兩個面向評分（1-4分量表）：

**相關性**（此題是否確實測到該構念）：
1 = 不相關　2 = 稍微相關　3 = 相關　4 = 非常相關

**清晰度**（題目文字是否清楚易懂、不會產生歧義）：
1 = 不清楚　2 = 需大幅修改　3 = 需稍微修改　4 = 非常清楚

## CVI 計算方式（供研究者事後使用）

**題項層級CVI（I-CVI）** = 評「3」或「4」的專家人數 ÷ 專家總人數
**量表層級CVI（S-CVI/Ave）** = 所有題項I-CVI的平均值

一般建議標準：I-CVI ≥ .78（專家數在3-5人時）、S-CVI/Ave ≥ .90 為可接受。
低於標準的題項應依專家意見修改後，再次確認或於問卷正式定稿前捨棄。
